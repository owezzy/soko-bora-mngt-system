# client/soko-bora-web-app — Angular Frontend

Angular 19 admin app based on the **Fuse** template. Communicates with the Go backend via ConnectRPC (not REST).

## Commands

```bash
npm start                  # ng serve with proxy to localhost:8080
npm run build              # Production build → dist/fuse/
npm run generate           # buf generate (regenerate proto TS stubs)
npm run watch              # Development build watcher
npm test                   # Karma + Jasmine unit tests
```

## Key Structure

```
src/
  @fuse/                   # Fuse UI framework (components, directives, pipes, theming)
  app/
    core/                  # Auth, navigation, user, i18n (transloco), services
    layout/                # App shell layouts
    mock-api/              # Mock API data for development
    modules/               # Feature modules: admin/, auth/, landing/
  connect/                 # ConnectRPC client integration (custom Observable wrapper)
  proto/                   # GENERATED — TypeScript protobuf stubs (DO NOT EDIT)
  styles/                  # Global SCSS + Tailwind entry
```

## ConnectRPC Integration (Non-Obvious)

The app uses ConnectRPC (not REST/gRPC-Web directly). The wiring is in `src/connect/`:

- `connect.module.ts` — `provideConnect()` / `provideGrpcWeb()` Angular providers for transport
- `observable-client.ts` — Custom wrapper that converts ConnectRPC calls to RxJS `Observable`
- `tokens.ts` — Angular DI tokens for each service client (e.g. `CustomerGrpcService`)

To add a new service client:
1. Proto stubs auto-generated into `src/proto/<module>pb/` by `npm run generate`
2. Create token in `tokens.ts`: `export const MyService = createClientToken(MyServiceDesc)`
3. Inject via Angular DI: `inject(MyService)`

Current wrapper only handles **unary** and **server-streaming** methods. Client-streaming and bidi-streaming are not implemented in `observable-client.ts`.

## Conventions

- **Proxy**: Dev server proxies only `/customerspb.**` → `localhost:8080` today. If you add or use other generated clients (`basketspb`, `depotpb`, `notificationspb`, `orderingpb`, `paymentspb`, `searchpb`), update `proxy.conf.json` or dev-mode calls will fail.
- **Styles**: SCSS components + Tailwind CSS. Tailwind uses custom Fuse plugins for theming (`src/@fuse/tailwind/plugins/`).
- **Tailwind config**: Custom font sizes (smaller than default), custom breakpoints (`sm:600, md:960, lg:1280, xl:1440`), disabled core plugins (float, clear, container, appearance, placeholderColor, placeholderOpacity, verticalAlign).
- **ESLint**: No component selector prefix required (empty prefix). Explicit return types enforced. Max line length 180.
- **Prettier**: Single quotes only. Plugins: organize-imports, tailwindcss.
- **tsconfig**: `baseUrl: ./src` — imports resolve from `src/` (e.g. `import { x } from 'app/core/...'`).
- **Routing/layout**: `app.routes.ts` uses route arrays + lazy `loadChildren(...)`, `LayoutComponent`, and `AuthGuard` / `NoAuthGuard` rather than NgModule routing.
- **Mock API**: `provideFuse()` enables `MockApiService` with `delay: 0` in `app.config.ts`. That means mock handlers are still wired during development unless you remove them.
- **Auth provider**: `provideAuth()` registers an HTTP interceptor via `withInterceptors([authInterceptor])`.
- **Auth interceptor gotchas**: it injects bearer tokens, adds client-side `Access-Control-Allow-*` headers, and hard-reloads the page on 401 via `location.reload()`.
- **Build budgets**: production build warns at 3 MB initial bundle / 75 KB component style and errors at 5 MB / 90 KB.
- **i18n**: Transloco is configured; root translations live in `src/assets/i18n/`.
- **Tests**: Karma/Jasmine is configured, but there are currently no `*.spec.ts` files in this app.

## Do Not Edit

- `src/proto/` — Generated by `buf generate` from Go-side `.proto` files. Regenerate via `npm run generate` or `go generate ./...` from project root.
- `src/@fuse/` — Fuse framework vendored code. Modify only for project-specific customizations.
